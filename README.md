# となりの、いつもの席

[ゲームを開く](https://usaginchaku.github.io/jj-novelgame/)

非公式の大学AUノベルゲームです。全39人、それぞれ独立した世界で6種類のエンドを遊べます。登場人物は全員20歳以上。初期名は「名字　なまえ」で、開始前に変更できます。

## 遊び方

相手を選び、名前を入力して「新しい日々をはじめる」を押します。本文は場面ごとにまとめて表示され、末尾の選択肢で進みます。仮の日付と朝・昼・夕方・夜を表示します。

友情、主人公からの告白、相手からの告白、親密な友人関係、その先の交際、人物固有のSPECIALが、同格の6エンドです。親密な場面は双方の合意と暗転で描きます。教員・助教の世界は全ての指導・評価・研究上の利害が終了した卒業後です。

「メッセージ」「回想」「エンド一覧」で記録を読み返せます。関係値は初周非表示で、クリア後の周回では設定から表示できます。

## セーブのバックアップ

世界ごとにオートセーブと手動3枠があります。「データ管理」から、残したい世界ごとにJSONを書き出してください。復元するときは同じ世界を選び、内容を確認して読み込みます。復元前の生データも退避できます。

保存先は利用中のブラウザーです。ブラウザーのデータ消去で記録も消えるため、JSONを手元へ保管してください。ローカル版と公開版は保存場所が違い、移動には世界ごとのJSONが必要です。個人のセーブがGitHubへ送られることはありません。

## このリポジトリ

検証済みの静的ゲームファイルを収録しています。GitHub Pagesから利用でき、AI APIや外部データベースは使いません。ローカルで読む場合はHTTPサーバーでこのフォルダを配信してください。HTMLファイルの直接起動には対応していません。

原資料、執筆用プロンプト、個人のセーブ、内部の作業資料は含めていません。

## 動作確認

開発側で573件のテストとビルドを確認し、Chromeの同じ保存領域で全39人・234エンドへ通常選択から到達しました。セーブとJSONの復元、旧名の回想、390px幅の操作を確認しています。Firefox・Safari・実機モバイルと長期間の大量周回は未検証です。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

[http://127.0.0.1:8000/](http://127.0.0.1:8000/) を開きます。
